## 先把几个绕不开的概念捋清楚

很多人搜"洛杉矶住宅 IP VPS"的时候，其实并不完全清楚自己要的到底是什么类型的产品。这几个词经常被混在一起说，但它们指的不是一回事。

**住宅 IP（Residential IP）**：IP 归属显示为家庭宽带运营商，而不是数据中心。你在 ipinfo.io 或者 ip.ping0.cc 上查，ASN 类型会标成 ISP 而不是 hosting。这种 IP 在各大平台的风控系统里"信任度"更高，不容易被一刀切。

**双 ISP**：更进一步，IP 的 ASN 和它所属的运营商公司都是本土家庭宽带类型，纯净度比单 ISP 更高。CstoneCloud 洛杉矶机房主打的就是这种双 ISP 住宅 IP，实测 ASN 和 Company 都显示为 ISP 类型。

**原生 IP**：IP 的注册地和机房物理位置一致。洛杉矶机房给的就是洛杉矶归属的 IP，不会出现"机器在美国、IP 归属显示在加拿大"这种割裂情况。注意，原生 IP ≠ 住宅 IP，原生 IP 也可以是机房 IP。CstoneCloud 同时提供两种：一种是住宅双 ISP 版（IP 是家宽属性），一种是原生 IP 版（IP 是机房属性但归属洛杉矶），两者线路都是 9929，价格差一截。

**AS9929 线路**：中国联通的精品回程骨干网，地位类似于电信的 CN2 GIA。回程走 9929 的好处是从美国回国内的延迟和稳定性比普通 BGP 好很多，三网（电信/联通/移动）都有优化。CstoneCloud 洛杉矶机房走的就是"直连 + 五网回程 9929"，官方原话是"媲美 CN2 GIA"。
